{# One figure, said once. The queue's band tiles, the case register's counters and the admin metrics were three near-identical patterns written three different ways. This is the one shape: an eyebrow, a figure set in the data face, an optional qualifier, and an optional share-of-total bar. The bar is an SVG sized by *attribute*, never by a `style` attribute — `security/headers.py` sets a `style-src` whose only hash is the empty string, so an inline style would be dropped and the bar would silently read as zero.
